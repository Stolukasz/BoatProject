# Boat Simulator

A simple boat simulation project created in Unity using C#.

## **Features**
- Sail opening and folding
- Sail rotation
- Boat movement and steering
- Acceleration and water drag
- UI displaying sail parameters

## **Technologies**
- Unity
- C#
- UI Toolkit

## **How to Run**
1. Clone the repository.
2. Open the project in Unity Hub.
3. Open the main scene.
4. Press **Play**.

## **Controls**
Player input is configured through the project's input system.
